# mr-insight（みえるマン）

このリポジトリはモノレポ構成です。

- `frontend/` : React（Vite）アプリ本体
- `backend/` : 将来のバックエンド（未実装）
- `ai/` : AI開発メモ・プロンプトなど

## 開発

```bash
cd frontend
npm install
npm run dev
```

## GitHub Pages

`main` への push で GitHub Actions がビルドし、GitHub Pages にデプロイします。
