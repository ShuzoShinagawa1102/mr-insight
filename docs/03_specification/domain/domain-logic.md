# ドメインロジック仕様

プラットフォームが「稼げる」判断を支援するために必要な，**評価ロジック・計算ロジック・判断ルール**を定義する．
各ロジックは，ドメインモデルの属性・関係を入力とし，`指標` / `バリュエーション` / `推奨アクション` を出力する．

---

## 1. 評価ロジック

### 1-1. 企業品質スコア

企業の本質的な強さを 0〜100 のスコアで表現する複合指標．

```
品質スコア = w1 * 収益性スコア
           + w2 * 成長性スコア
           + w3 * 財務健全性スコア
           + w4 * ガバナンススコア
           + w5 * ESGスコア
```

| 構成要素 | デフォルトウェイト | 主な入力指標 |
|---|---|---|
| 収益性スコア | 30% | ROE, ROA, ROIC, 営業利益率, EBITDA マージン |
| 成長性スコア | 25% | 売上成長率（CAGR 3yr）, EPS 成長率, FCF 成長率 |
| 財務健全性スコア | 20% | Net Debt / EBITDA, 流動比率, インタレスト・カバレッジ |
| ガバナンススコア | 15% | 独立取締役比率, 監査意見, 開示品質 |
| ESGスコア | 10% | ESG フレームワーク別スコア（TCFD 等） |

各構成要素は 0〜100 に正規化（業種別ピア比較による偏差値換算）．
外れ値は IQR ベースでウィンソライズする．

---

### 1-2. 投資魅力度評価

バリュエーション・モメンタム・カタリストを組み合わせた多面評価．

```
魅力度スコア = バリュエーション割安度
             × 成長モメンタム
             × カタリスト期待度
             × (1 - リスク割引)
```

| 要素 | 評価方法 |
|---|---|
| バリュエーション割安度 | P/E, EV/EBITDA, P/FCF の対ピア割引率（≥ 20% 割安で高評価） |
| 成長モメンタム | 直近 2Q の売上 / EPS の上方サプライズ率 |
| カタリスト期待度 | 未解決 `仮説` のうち thesis-positive な割合 |
| リスク割引 | `リスク.発生可能性 × リスク.影響度` の加重平均（0〜1 に正規化） |

---

### 1-3. ガバナンス評価

```
ガバナンススコア = (独立取締役比率 × w_board)
                + (監査意見ポジティブ × w_audit)
                + (開示品質スコア × w_disclosure)

デフォルト: w_board = 0.4, w_audit = 0.3, w_disclosure = 0.3
```

各ウェイト（`w_board`, `w_audit`, `w_disclosure`）は `シナリオ` に紐付く前提条件として管理し，
規制環境や投資方針に応じて上書き可能とする．

- **独立取締役比率**: `独立 取締役会席 数 / 全 取締役会席 数`
- **監査意見ポジティブ**: 適正意見 = 1.0, 限定付適正 = 0.5, 不適正 / 意見拒絶 = 0.0
- **開示品質スコア**: `開示書類` の `会計基準` 水準と過去の業績修正件数から算出（修正なし = 1.0, 修正 n 件増加ごとに -0.1）

---

### 1-4. リスク評価

```
リスクスコア（企業） = Σ [ リスク.発生可能性 × リスク.影響度 ]
                    / (全 リスク 数 × max_発生可能性 × max_影響度)
```

- スコアが 0.7 以上の企業は「高リスク」フラグ
- 個別 `リスク` の `影響度 ≥ 4 AND 発生可能性 ≥ 4` の場合，`CRITICAL` としてアラート

## 2. 計算ロジック

### 2-1. 財務メトリクス計算

以下はすべて `指標.計算式` として管理し，`財務数値.報告値` から `指標.値` を生成する際に適用する．

| 指標名 | 計算式 | 対応 財務数値ラベル |
|---|---|---|
| 売上成長率（YoY） | `(売上高_t - 売上高_t-1) / 売上高_t-1` | 売上高 |
| 営業利益率 | `営業利益 / 売上高` | 売上高・営業利益 |
| EBITDA | `営業利益 + 減価償却費` | 営業利益・減価償却費 |
| EBITDA マージン | `EBITDA / 売上高` | — |
| ROE | `当期純利益 / 平均自己資本` | 当期純利益・自己資本 |
| ROA | `当期純利益 / 平均総資産` | 総資産 |
| ROIC | `NOPAT / 投下資本` | — |
| EPS | `当期純利益 / 加重平均発行済株数` | — |
| FCF | `営業CF - 設備投資額` | 営業CF・設備投資額 |
| Net Debt | `有利子負債合計 - 現預金` | 有利子負債・現預金 |
| Net Debt / EBITDA | `Net Debt / EBITDA` | — |
| インタレスト・カバレッジ | `EBIT / 支払利息` | — |

**正規化ルール（`財務数値.正規化値` 生成時）**:
1. 非継続事業損益を除外
2. 一時損益（業績修正対象含む）を除外
3. 為替換算は `開示書類.期間終了日` 時点の中間レートを使用
4. スケール（百万円 / 千ドル等）は `財務数値.スケール` を参照して統一

---

### 2-2. バリュエーション計算

#### DCF（Discounted Cash Flow）

```
本源的価値 = Σ [FCF_t / (1 + WACC)^t]  (t = 1..n)
           + 継続価値 / (1 + WACC)^n

継続価値 = FCF_n × (1 + g) / (WACC - g)
```

- `WACC` は `シナリオ.WACC` として管理（デフォルト：リスクフリーレート + ベータ × エクイティリスクプレミアム）
- `g`（永続成長率）は `シナリオ.永続成長率` として各 `シナリオ` に紐付け
- 出力は `バリュエーション.株式価値`, `バリュエーション.目標株価` に記録

#### 比較倍率法（Comparable Multiples）

```
目標株価_EV = Median(ピア EV/EBITDA) × 当社EBITDA
目標株価_PE = Median(ピア P/E) × 当社EPS
目標株価   = (目標株価_EV + 目標株価_PE) / 2
```

- ピアグループは `競合関係.関係タイプ = peer` で定義
- アウトライアー除去：P/E が負またはデータなしの企業は除外

---

### 2-3. マーケットシェア計算

```
シェア_i = 企業_i_売上高 / Σ(市場内全企業の売上高)
```

- `指標`（`指標名 = 市場シェア`）として記録
- 集計基準（売上高 / 販売数量 / 金額）は `指標.値タイプ` で区別
- 年次・半期・四半期ごとに観測値を作成

---

### 2-4. シナリオ加重バリュエーション

```
加重目標株価 = Σ [ シナリオ_i.確率 × バリュエーション_i.目標株価 ]
```

- 全 `シナリオ` の確率合計 = 1.0 であることをバリデーション（許容誤差は下記「データ整合性バリデーション」参照）
- シナリオ数は柔軟（最低 2 つ）．典型的には強気 / 基本 / 弱気の 3 シナリオを推奨するが，規制変化・破壊的革新など追加シナリオも許容
- 出力は `投資仮説` に紐付く `バリュエーション` に反映

---

### 2-5. 監視指標の更新

`監視ルール.トリガー条件` の評価は以下の順序で行う：

1. `開示書類公表` イベント受信 → `指標` を再計算
2. 各 `監視ルール.トリガー条件`（例：`ROE < 0.08`）を評価
3. 条件成立 → `監視ルール発動` イベントを発火

## 3. 判断ルール

### 3-1. 投資推奨ルール

| 条件 | 推奨アクション | 確信度 |
|---|---|---|
| `加重目標株価 / 現在株価 ≥ 1.30` AND `品質スコア ≥ 70` AND `リスクスコア < 0.4` | `BUY` | `HIGH` |
| `加重目標株価 / 現在株価 ≥ 1.15` AND `品質スコア ≥ 50` | `BUY` | `MEDIUM` |
| `0.90 ≤ 加重目標株価 / 現在株価 < 1.15` | `HOLD` | `MEDIUM` |
| `加重目標株価 / 現在株価 < 0.90` AND `リスクスコア ≥ 0.6` | `SELL` | `HIGH` |
| `加重目標株価 / 現在株価 < 0.90` | `SELL` | `MEDIUM` |
| `リスクスコア ≥ 0.8` | `SELL` | `HIGH`（リスク優先ルール） |

- 上記ルールは優先順位順（リスク優先ルールが最上位）
- `推奨アクション.根拠` に適用されたルール ID と入力値を記録

---

### 3-2. 仮説ステータス更新ルール

```
状態遷移: 草案 → 検証中 → 確認 / 棄却 / 陳腐化
```

| 遷移 | 条件 |
|---|---|
| `草案 → 検証中` | `検証方法` に対応するデータが取得可能になった |
| `検証中 → 確認` | `棄却条件` が **成立しない** まま `検証方法` の結果が想定範囲内に収まった |
| `検証中 → 棄却` | `棄却条件` が成立（例：「3Q 連続で ROE < 8%」等） |
| `検証中 → 陳腐化` | 関連 `開示書類` が 2 期以上未更新，または仮説の有効期限超過 |

---

### 3-3. アラート発火ルール

以下の条件を満たした場合，`監視ルール発動` イベントを生成し，ユーザーに通知する．

| 分類 | 条件 | 優先度 |
|---|---|---|
| バリュエーション乖離 | `|現在株価 - 加重目標株価| / 加重目標株価 ≥ 0.20` | HIGH |
| 財務悪化 | `Net Debt / EBITDA ≥ 5.0` OR `インタレスト・カバレッジ < 1.5` | HIGH |
| ガイダンス下方修正 | `業績予想修正` イベント + 修正幅 ≥ -10% | MEDIUM |
| 仮説棄却 | `仮説棄却` イベント発火 | HIGH |
| 経営陣交代 | `経営陣交代`（CEO / CFO / CTO） | MEDIUM |
| 重大リスク出現 | `リスク.発生可能性 ≥ 4 AND リスク.影響度 ≥ 4` | HIGH |

---

### 3-4. ポートフォリオ構築ルール

プロ投資家がポートフォリオを組む際のガードレール．

| ルール | 内容 |
|---|---|
| 集中度制限 | 単一銘柄の `持分保有.持分比率` が NAV の 20% を超えない |
| セクター分散 | 同一 `業種分類.コード`（大分類）への配分が NAV の 40% を超えない |
| 国別分散 | 同一 `組織.国コード` への配分が NAV の 50% を超えない |
| 流動性チェック | `上場フラグ = false` の企業への合計配分が NAV の 30% を超えない |
| リスク上限 | ポートフォリオ全体の加重平均 `リスクスコア ≥ 0.6` の場合，新規 BUY 推奨を停止 |

---

### 3-5. データ整合性バリデーション

| チェック項目 | ルール |
|---|---|
| シナリオ確率合計 | `Σ シナリオ.確率 = 1.0 (± PROBABILITY_TOLERANCE)`．`PROBABILITY_TOLERANCE` はシステム定数（デフォルト 0.001）として設定ファイルで管理 |
| 持分合計 | `Σ 持分保有.持分比率 ≤ 1.0`（同一 `企業` の同一 `基準日`） |
| 財務期間整合 | `開示書類.期間開始日 < 開示書類.期間終了日` |
| バリュエーション通貨 | `シナリオ` 内の全 `バリュエーション.通貨` が一致 |
| ガイダンス矛盾 | `業績予想.下限 ≤ 業績予想.上限` |
| 在任期間 | `取締役会席.就任日 ≤ 取締役会席.退任日` |
